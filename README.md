# 🤖 روبوت تحميل الوسائط (Python + python-telegram-bot)

بوت تيليغرام يحمّل الفيديو من:
- **YouTube** • **Instagram** • **TikTok** • **Facebook**
- مع **بحث على يوتيوب** بالاسم → اختيار MP3 صوت أو MP4 فيديو

## ⚡ التشغيل السريع
```bash
# مرة واحدة فقط
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
sudo apt install ffmpeg

# كل مرة تريد تشغيل البوت
./start.sh      # تشغيل في الخلفية
./stop.sh       # إيقاف
tail -f bot.log # متابعة السجل
```

## 🔑 الإعداد (ملف .env)
```
BOT_TOKEN=توكن_البوت
OWNER_ID=ايدي_المالك
```

## 👑 لوحة المالك (ظاهرة للمالك فقط)
زر «👑 لوحة المالك» في الأزرار النظامية أو `/owner`:
- 📊 إحصائيات البوت
- 📢 إذاعة رسالة لكل المستخدمين
- 🔐 تعيين/إزالة قناة **الاشتراك الإجباري**
- ⚙️ الإعدادات + 📥 تعديل الحدود اليومية
- 👑 منح/خصم نقاط • 🚫 حظر/فك حظر
- 🎁 **رابط هدية** (محدود بعدد استخدامات ونقاط لكل مستخدم)
- 👥 أفضل المستخدمين • 🛑 إيقاف البوت

> ⚠️ لتعيين القناة: أرسل `@username` أو `-100xxxxxxxxxx` ويجب أن يكون **البوت مشرفاً** في القناة.

## 🎁 روابط الهدية
من لوحة المالك اضغط «🎁 رابط هدية» ثم أرسل مثلاً:
- `5` → رابط يستقبل **5 أشخاص**، كل واحد يكسب **10 نقاط**
- `5 20` → 5 أشخاص × 20 نقطة
الرابط يتعطل تلقائياً بعد اكتمال العدد المحدد.

## 🎁 النقاط وVIP
- كل تحميل ناجح = **+1 نقطة**
- كل صديق دخل برابط دعوتك = **+5 نقاط**
- مكافأة يومية /daily أو زر «🎁 مكافأة يومية» = **+5 نقاط/يوم**
- عند **100 نقطة** → **VIP** تلقائياً:
  - ✅ بدون اشتراك إجباري
  - ✅ أولوية أعلى في قائمة التحميل
  - ✅ جودة حتى 1080p (العادي 720p)
  - ✅ حد يومي أعلى (الافتراضي: 20 مقابل 3)

## 📱 الأزرار النظامية (ReplyKeyboard)
- **📥 تحميل/بحث** • **👤 حسابي** (إحصائيات + شريط تقدم VIP + آخر تحميلات)
- **🎁 مكافأة يومية** • **🔗 رابط الدعوة** • **ℹ️ المساعدة**
- **👑 لوحة المالك** (للمالك فقط)

## 🔔 إشعارات للمالك
عندما يدخل **مستخدم جديد** لأول مرة يصل المالك إشعار فوري باسم المستخدم وID واليوزرنيم ومصدر الدخول (مباشرة أو من رابط دعوة).

## 📁 هيكل المشروع
- `run.py` → نقطة الدخول
- `bot/main.py` → تجميع التسجيل
- `bot/handlers/` → وحدات منفصلة (start, media, help, owner, callback, subscription, system)
- `bot/jobs.py` → طابور التحميل والرفع
- `bot/state.py` → الحالة المشتركة
- `bot/db.py` → قاعدة بيانات SQLite (مستخدمين/نقاط/تحميلات)
- `bot/downloader.py` → yt-dlp + ffmpeg
- `bot/config.py` → الإعدادات
- `bot/cookies/` → ضع `instagram.txt`, `tiktok.txt`, `facebook.txt` إن احتجت كوكيز

## ⚠️ ملاحظات
- حد رفع بوت API = **50MB** للملف الواحد.
- انستا/تيك توك قد تحتاج كوكيز (توضع في `bot/cookies/`).
- ملفات التحميل تُحذف تلقائياً بعد 24 ساعة.
